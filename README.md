# Лабораторная работа №3
## Паттерны Bridge и Composite  



## Используемые паттерны

### 1️ Composite

Позволяет представлять граф как древовидную структуру:

- `GraphComponent` — общий интерфейс
- `Vertex` — лист (вершина)
- `SubGraph` — составной объект (подграф)
- `Graph` — основной граф

Благодаря этому граф может содержать вершины и подграфы.

---

### 2️⃣ Bridge

Разделяет абстракцию графа и способ хранения рёбер.

**Абстракция:**
- `Graph`

**Реализация:**
- `GraphStorage` (интерфейс)
- `AdjacencyListStorage`
- `AdjacencyMatrixStorage`

Позволяет переключать способ хранения во время выполнения программы.
